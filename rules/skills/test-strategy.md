# test-strategy skill

- skill-id：`test-strategy`
- 目的：受入基準と再現可能な検証・再試行・中断・再開を定義する。
- 適用範囲：skill導入・変更の検証計画。
- 発動条件：受入基準、検証対象、期待値が必要になった場合。
- 入力：要求、変更対象、受入基準、停止条件。
- 出力：検証観点、期待値・実際値・根拠、判定、再開条件。
- 状態：候補／発動中／成功／停止／失敗／中断。
- 優先順位・競合：Owner承認とgrillを優先し、検証不能な場合は成功扱いにしない。
- 停止条件：期待値・根拠不足、再現不能、同一検証2回連続失敗、未確認のままの受入。
- 証跡先：Tester result、operation-check、task-log。
- 検証基準：失敗・再試行・中断・再開を記録し、受入と効果確認を分離できる。
- 効果指標・改訂条件：再現率、失敗再試行率、未確認率。閾値未達時は検証方式を改訂する。
