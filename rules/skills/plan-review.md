# plan-review skill

- skill-id：`plan-review`
- 目的：計画の実行可能性と境界を確認する。
- 適用範囲：Owner承認済み計画の実装前。
- 発動条件：計画、対象・対象外、依存、実行環境、停止条件、証跡が提示された場合。
- 入力：承認済みplan、current-task、関連正本。
- 出力：確認結果、未確認事項、停止または実装可否。
- 状態：候補／発動中／成功／停止／失敗／中断。
- 優先順位・競合：grillとOwner承認ゲートを優先し、責務競合は自動解消しない。
- 停止条件：必須情報欠落、計画外変更、正本不一致、未承認、依存不明。
- 証跡先：担当worker resultとtask-log。
- 検証基準：対象・対象外・依存・環境・停止条件・証跡が揃い、未解決時に停止できる。
- 効果指標・改訂条件：計画外変更の検出率、停止漏れ。閾値未達時は改訂をOwner判断へ返す。
