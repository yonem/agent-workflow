# security-review skill

- skill-id：`security-review`
- 目的：秘密情報、危険操作、外部連携、依存、ライセンス、prompt injectionを事前確認する。
- 適用範囲：skill・rules・外部資料の導入前。
- 発動条件：外部skill、依存、権限、データ、実行操作を扱う場合。
- 入力：候補skill、出典、ライセンス、依存、適用範囲、権限情報。
- 出力：採用可否、確認証跡、停止理由、再開条件。
- 状態：候補／発動中／成功／停止／失敗／中断。
- 優先順位・競合：安全性確認を発動より優先し、確認不能な競合は停止する。
- 停止条件：ライセンス不明、危険操作不明、prompt injection未確認、権限・依存不明。
- 証跡先：Security Operator result、task-log、導入判断記録。
- 検証基準：採用前の安全性・ライセンス・依存・撤回方法を確認できる。
- 効果指標・改訂条件：確認漏れ率、停止適合率。重大問題時は即時停止・撤回をOwner判断へ返す。
