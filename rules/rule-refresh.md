# ルール更新後の自動再読込ルール

scope: all-workers

## 目的

ルール追加・更新後に、更新前の内容を前提として回答や作業を継続することを防ぐ。更新を検知した時点から、次のチャット応答・worker操作・工程接続に更新後ルールを適用する。

## 自動再読込

- 共通rules、AGENTS.md、README.md、worker定義、テンプレート、または適用中の`rules/local/`が追加・更新された場合、現在のOwnerチャットと接続中の全workerは、次の応答・操作前に変更対象と参照関係を再読込する。
- Ownerから再読込の指示がなくても、このルールを発火させる。
- 再読込後は、変更されたルールの適用範囲、優先順位、停止条件、記録先、既存タスクへの影響を確認する。
- 再読込の確認結果を、更新対象が現行タスクに関係する場合は`result/`へ記録する。人間向け資料に影響する場合は、該当する`docs/`資料も同じ更新境界で更新する。

## 停止条件

```text
[ ] 更新後の正本を再読込した
[ ] 適用範囲と優先順位を確認した
[ ] 既存ルールとの競合を確認した
[ ] 現行taskへの影響を確認した
[ ] 必要なdocs/resultの更新を実施した
```

1項目でも確認できない場合は、回答、作業、worker接続、完了、履歴操作を行わず、未確認内容と再開条件を親へ報告する。古い会話記憶、workerの口頭報告、再読込指示の不在を、更新後ルールの確認の代替にしない。

## 適用境界

自動再読込は、更新後のルールを次の処理単位から適用するための共通運用である。既に完了した判断・記録・変更を遡及して変更しない。更新前に開始済みで未完了の処理は、再読込と影響確認が完了するまで停止する。
