# 開発サイクル改善記録

汎用的な開発サイクルの改善点を記録する。記載方法は `rules/development-improvement-record.md` に従い、個別タスクの詳細は対象プロジェクトの `result/task-log.md` に記録する。

## 記載ルール

- 1改善項目を1ブロックで記録する
- 汎用化できる改善点だけを記録する
- 改善項目は `評価中` と `評価済み` に分ける
- `評価済み` には `対応完了` と `適用外` をまとめる
- 作業の進捗はworkerタスクで管理する

## ステータス

- 評価中
- 対応完了
- 適用外
