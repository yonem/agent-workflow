# 開発サイクル改善記録

このファイルは、特定プロジェクトや単一タスクに依存しない、開発プロセス上の改善点・課題・再利用可能な教訓を一覧管理する。個別タスクの詳細、実装内容、ログは `result/task-log.md` に記録する。

## 記録ルール

- 1改善項目につき1行とする
- 既存項目は削除せず、状態・対応案・次回確認日を更新する
- 個別プロジェクトの固有名、パス、具体的なログは原則として記録しない
- セル内の文章は簡潔にし、詳細が必要な場合はタスク固有ログへ記録する
